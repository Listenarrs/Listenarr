# E2E audiobook fixtures

The browser E2E suite imports these files as fake audiobooks. They are one second of silence in a
real MP4/M4B or MP3 container, with the tags the scan reads through `ffprobe` (`album`,
`album_artist`, `SERIES`, `SERIES-PART`, `ASIN`). Empty/touched files would have no tags, so the
scan could not derive the titles, authors, series, ASINs or the three-part grouping the specs assert.

| File | Tags that matter |
| --- | --- |
| `B008DFUGCQ.m4b` | album `Barsoom`, author `Edgar Rice Burroughs`, ASIN `B008DFUGCQ` |
| `B0C6B525PQ.m4b` | album/author `Tanar of Pellucidar` / `Edgar Rice Burroughs`, no ASIN |
| `no-tags.m4b` | no tags at all: the scan falls back to the folder name `Pellucidar` |
| `B0096QR7Z0-part.mp3` | album/author `Allan Quatermain` / `H. Rider Haggard`; copied to three part files |
| `B01FKWL15A.m4b` | album `Captain Nemo`, author `Jules Verne`, ASIN `B01FKWL15A` |
| `B002V5B7TK.m4b` | album `Tarzan`, author `Edgar Rice Burroughs`, ASIN `B002V5B7TK` |

Provenance: generated by `https://github.com/m4bard/listenarr-testdata` at
`bd59f6f9a891a70b3cccb644b9ae0fc3f50a5ecd`, with `tools/generate_library.py --scenario happy-path
--layout author-title --ffmpeg-source system --seed 1` and the tag states/structures used by the old
`generate-library-fixtures.sh`. To regenerate, clone that revision, run the six `generate` calls from
the old script and copy the resulting files here. Committing them removes the CI `ffmpeg` /
`python3-venv` install and the pip install from the E2E path; the test host still needs `ffprobe` to
read the tags.
